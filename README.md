# Netflix Clone – Tailwind CSS

A responsive Netflix landing page clone built with **HTML and Tailwind CSS**. This project focuses on recreating Netflix's modern UI while practicing responsive layouts, CSS Grid, positioning, and Tailwind utility classes.

### Features

* Responsive Netflix-style landing page
* Hero section with background image and overlay
* Responsive Grid layouts
* Embedded video sections
* FAQ section
* Download and kids profile sections
* Responsive footer
* Mobile, tablet, and desktop layouts

### Tech Stack

* HTML5
* Tailwind CSS
* Font Awesome

### Purpose

Built as a **Tailwind CSS practice project** to strengthen responsive web design and utility-first CSS skills.
